# Agent Protocol

Substantial work on this repo defaults to OpenCode with MiniMax-M3 on the worker.

- Inspect before edit; read the failing code path, not just the symptom.
- Use the smallest root-cause / native solution. No speculative features (YAGNI).
- Preserve unrelated changes; never revert or rewrite work outside the assigned task.
- Run the relevant tests; report the exact commands and their results.
- Do not reveal secrets, tokens, account data, or slot/trading state.
- Only commit, push, or deploy when the assigned task explicitly permits it.
- Keep edits scoped to the files named in the task; ask before expanding scope.
- When in doubt, stop and ask rather than guess.
